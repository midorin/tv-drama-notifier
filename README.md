# 📺 テレビドラマ再放送通知アプリ

お気に入りのテレビドラマを登録して、再放送を見逃さないためのWebアプリです。

## 🌟 特徴

- **シンプルな操作**: ドラマタイトルを入力するだけで簡単に登録
- **ローカル保存**: ブラウザのローカルストレージにデータを保存（サーバー不要）
- **通知機能**: ブラウザ通知をサポート
- **レスポンシブデザイン**: スマートフォンでも快適に使用可能
- **オフライン動作**: インターネット接続不要で動作

## 📋 機能一覧

### ✅ 実装済み機能

1. **ドラマ登録機能**
   - ドラマタイトル（必須）
   - 放送年（任意）
   - メモ欄（任意）

2. **登録済みドラマの管理**
   - 登録したドラマの一覧表示
   - ドラマの削除機能
   - 登録日時の表示

3. **データ永続化**
   - ローカルストレージへの自動保存
   - ブラウザを閉じてもデータが残る

4. **通知設定**
   - ブラウザ通知の有効化
   - 通知ステータスの表示

## 🚀 使い方

### 基本的な使い方

1. `index.html` をブラウザで開く
2. 「ドラマを登録」セクションでドラマ情報を入力
3. 「登録する」ボタンをクリック
4. 登録済みドラマ一覧に表示される

### 通知を有効にする

1. 「通知設定」セクションの「通知を有効にする」ボタンをクリック
2. ブラウザの通知許可ダイアログで「許可」を選択

### ドラマを削除する

1. 登録済みドラマ一覧から削除したいドラマの「削除」ボタンをクリック
2. 確認ダイアログで「OK」を選択

## 💡 活用方法

### 現在の使い方（v1.0）

1. 気になるドラマのタイトルを登録
2. 定期的に番組表サイトで再放送情報をチェック
3. 再放送が見つかったら、メモ欄に詳細を記録
4. 録画予約を忘れずに設定

## 🛠 技術仕様

- **HTML5**: セマンティックなマークアップ

- **Vanilla JavaScript**: フレームワーク不要

- **Notification API**: ブラウザ通知

## 📝 データ形式

登録されたドラマは以下の形式でローカルストレージに保存されます：

```json
{
  "id": 1234567890,
  "title": "コウノドリ",
  "year": "2015",
  "notes": "第3話から見たい",
  "createdAt": "2025-11-16T12:00:00.000Z"
}
```

## 🔒 プライバシー

- すべてのデータはブラウザのローカルストレージに保存されます
- サーバーへのデータ送信は一切ありません
- インターネット接続なしで完全に動作します
